# 🎓 Student Management System

A web-based Student Management System designed to manage student records through a simple and responsive admin dashboard.

## 🚀 Live Demo

GitHub Pages:
https://santhosh12356.github.io/Student-Management-System/

## 📌 Features

- 🔐 Admin Login
- 📊 Admin Dashboard
- ➕ Add Student
- ✏️ Edit Student
- 🗑️ Delete Student
- 🔍 Search Student
- 📈 Department-wise Statistics
- 📥 Export Student Data as CSV
- 💾 Local Storage
- 📱 Responsive Design
- 🌐 GitHub Pages Deployment
